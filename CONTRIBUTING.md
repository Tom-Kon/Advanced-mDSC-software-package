# Welcome to the Advanced mDSC software package contributing guidelines!

First and foremost, we greatly appreciate your willingess to contribute to this project. We invite you to consult our [Code of Conduct](./CODE_OF_CONDUCT.md)
to ensure a nice collaborative environment.

## Introduction
The latest verion (1.0.5) of the software focuses entirely on different mDSC deconvolution techniques. This includes:

- Deconvolution of quasi-isothermal mDSC data
- Deconvolution of standard mDSC data, with and without Fourier transform. 
- Computation of simple descriptive statstics related to mDSC data based on TRIOS templates. 
- mDSC deconvolution simulation, where experimentally gathered data is used to construct a modulated heat flow, which is then deconvoluted.

Quantitative mDSC analysis (peak integration, peak analysis, and so forth) is currently not included in the software. 

It should be noted that this document focuses on guiding those that wish to contribute to the code. If you simply have a suggestion or have found a bug, please refer to the "issues" tab.
